Documentation

Silent Whisper is a menu bar app. Hold a key, talk, and it types. Everything below is optional except the first two sections.

Install

Download the .dmg from the latest release and drag the app to Applications. It is signed with an Apple Developer ID and notarized by Apple, so it opens without a warning.

Requires macOS 14 or later on Apple silicon.

Permissions

macOS asks for two things on first launch. Both are needed.

MicrophoneTo hear you. Nothing is recorded to disk.
AccessibilitySo the hotkey works in any app, and so the app can press ⌘V for you.

If the hotkey stops working after an update, remove the old Silent Whisper entry in System Settings under Privacy & Security, then add the app again. Toggling it off and on is not enough.

Using it

Hold right ⌥Records while held. Release to transcribe and paste.
Click the blobStarts a hands free take. It ends itself once you stop talking.
Click againCancels a take that is still transcribing.

The text is always copied to the clipboard. With Paste automatically on, it is also pasted into whatever had focus.

The blob only appears while something is happening. When idle it is not on screen at all, and it costs nothing.

Microphone

By default Silent Whisper follows the system input, and it re-reads it at the moment you press — switch devices in System Settings and the next take uses the new one, no restart.

To ignore the system and always use one mic, pick it under Microphone. If that device is unplugged or asleep the app quietly falls back to the system input rather than failing, and goes back to your choice when it reappears.

Models

Speech recognition runs locally through WhisperKit on the Neural Engine. Bigger models are more accurate and slower. The first run of a model downloads it, then compiles it for the Neural Engine, which takes a few minutes once per model.

ModelSizeNotes
tiny~75 MBFastest and roughest. Weak outside English.
base~145 MBQuick, shaky on names and inflected endings.
small~465 MBThe default. Smallest model that handles non-English properly.
medium~1.5 GBBetter again, noticeably slower on long takes.
large-v3_turbo~1.6 GBMost accurate.
base.en, small.envariesEnglish only. Returns nonsense for other languages.

Models already on disk are marked with a check in the picker. If you select one you do not have yet, the best model you already have loads immediately and the new one downloads behind it, so you can keep dictating. You only wait when nothing at all is downloaded.

Languages

Language is one list of checkboxes, and how many you tick decides what happens.

NoneWhisper detects from all 99 languages. Short takes are where it guesses wrong.
OnePinned. No detection runs at all, so it can never land on another language.
SeveralDetection is limited to the ones you speak. Costs a moment before the text lands.

Tick the two or three languages you actually use and a stray one stops being possible. A take is still a single language either way: Whisper labels each 30 second window once, so half Türkçe and half Français in one recording does not work — the quieter half gets pushed through the other language.

The one trap worth knowing: the models whose names end in .en are English only. They do not fail on other languages, they return confident nonsense. For Türkçe, Deutsch, 日本語 and the rest, use a model without the suffix.

Vocabulary

Names, product names and acronyms that keep coming out wrong go in the vocabulary field, comma separated. These are fed to the Whisper decoder itself as a prompt, not just to the cleanup afterwards, so the fix happens at the source.

Nuh, WhisperKit, Anthropic, Ghostty, libghostty, Vesta

AI pass

An optional second pass over the transcription that fixes punctuation, casing and misheard words. It is off by default.

It can never cost you a dictation. If the pass fails for any reason, offline, bad key, out of credit, or slower than twelve seconds, the plain transcription is pasted anyway and a notification explains why. Results that look like a reply rather than a repair are rejected the same way.

ProviderKeyNotes
ApplenoneOn device. Nothing leaves the Mac. Good at English, unreliable on other languages.
AnthropicrequiredClaude. Strongest for non-English cleanup.
OpenAIrequiredAny chat completions model.
GooglerequiredGemini.

Styles

  • Clean up, fixes punctuation and removes filler, keeps your wording.
  • Punctuation only, adds punctuation and nothing else. Every word survives.
  • Professional, tightens rambling sentences and fixes grammar.
  • Custom, your own instruction.

API keys are stored in the macOS Keychain, never in preferences. Only the finished text is sent, never audio.

Look and motion

Four looks for the blob: Glass, which refracts the desktop behind it, plus Obsidian, Chrome and Pearl.

Motion follows the system Reduce Motion setting by default, and can be forced on or off. Reduced motion keeps the blob responsive to your voice but stops the satellites orbiting.

Privacy

Audio never leaves the Mac. Whisper runs locally, there is no account, no telemetry and no server.

The only outbound traffic is the model download on first run, a daily check for updates, and, if you turn it on, the finished text going to the AI provider you chose with a key you own.

Updates

The app checks for updates on launch and every few hours, and can install them in place. There is a Check button in Settings if you want to look now.

Build from source

Swift 5.10 or later, and Xcode command line tools.

# build SilentWhisper.app
scripts/build.sh

# regenerate the app icon
scripts/makeicon.sh

# check the blob geometry and the AI pass guards
.build/debug/SilentWhisper --selftest

# build, sign, notarize and publish a release
scripts/release.sh 1.1.1

Without an Apple Developer ID the build falls back to ad hoc signing, and macOS then revokes the Accessibility grant on every rebuild. With a certificate in your keychain the build picks it up and the grant sticks. Tagging a version pushes a signed, notarized release through GitHub Actions.
